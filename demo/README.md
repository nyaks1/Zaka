# Synthetic demo statement

`synthetic-fnb-statement.csv` and `synthetic-statement.pdf` are fake data for
testing the CSV/PDF import path. Every name, description and amount is invented.
It is not a real bank statement and contains no customer data.

To try it:

1. Open **Accounts** and choose a bank account.
2. Tap **Import statement**.
3. Choose **CSV**, then pick this file (or paste its contents).
4. Check the preview, especially that the ATM rows are classified as cash
   transfers, then import.

The file deliberately includes salary, taxi, food, airtime, electricity,
groceries, vendor and ATM rows so the category breakdown and the Ask Zaka tip
have something to work with.
